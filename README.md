## The line

> I asked my smart speaker to play something relaxing. It started reading my 4,312 unread emails out loud in a spa voice.

## How it runs

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Stdlib only, no dependencies.
